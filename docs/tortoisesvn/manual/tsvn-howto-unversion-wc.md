## Unversion a working copy

If you have a working copy which you want to convert back to a plain folder tree without the `.svn` directory, you can simply export it to itself. Read [the section called “Removing a working copy from version control”](tsvn-dug-export.md#tsvn-dug-export-unversion "Removing a working copy from version control") to find out how.
