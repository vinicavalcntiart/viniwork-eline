# TortoiseSVN Manual (mirror)

Mirror of the official TortoiseSVN manual (Version 1.14 docs, which also cover the 1.15 pristine-copy option), fetched 2026-10-16 from https://tortoisesvn.net/docs/release/TortoiseSVN_en/ and converted from HTML to Markdown with pandoc. Screenshots are not included; each one is replaced by its caption. The manual is part of the TortoiseSVN project and distributed under the GNU GPL.
