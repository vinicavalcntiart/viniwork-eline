## 14. TIME
Vini is in Recife, Brazil (America/Recife, UTC-3, no DST). Before any message that
touches time of day, deadlines, sleep, or Slack timestamps, run
`TZ=America/Recife date` and reason from that clock, not from the container's.
Slack screenshots show Vini's phone clock, which is already Recife time.
